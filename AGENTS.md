# Règles d'Ingénierie & Workflow Git — LightPath Training Portal

1. **Workflow Git Strict (Branche dédiée → Tests → Commit → Push → PR → Merge) :**
   - Aucun commit ni push direct sur `main`.
   - Exécution obligatoire de `php tests/run_tests.php` (100% de réussite exigée) avant tout commit.
