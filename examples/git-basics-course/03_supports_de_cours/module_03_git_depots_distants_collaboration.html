Module 03 : Dépôts Distants (clone, remote, fetch, pull, push) & Pull Requests

Formateur : Jean-Marie Renouard (LightPath SARL) • Durée : 2h30 • Niveau Bloom C3

Points Clés de la Collaboration Distante

  • Références distantes : origin désigne le serveur distant et refs/remotes/origin/* son miroir local.
  • Observation sûre : git fetch récupère les commits distants sans modifier votre branche locale.
  • Intégration maîtrisée : git pull --ff-only ou git pull --rebase évite les commits de fusion superflus.
  • Pull Request : branche dédiée, git push -u origin <branche>, revue par les pairs, fusion et nettoyage.

Commandes de Référence

Commande Direction du Flux Effet Opérationnel
git clone <url> Serveur → Local Copie le dépôt complet et configure le remote origin
git fetch origin Serveur → origin/* Met à jour les pointeurs distants sans toucher au Working Tree
git pull --rebase Serveur → Branche active Télécharge puis réapplique les commits locaux au-dessus de origin
git push -u origin feat Local → Serveur Publie la branche et configure le suivi amont (upstream)
