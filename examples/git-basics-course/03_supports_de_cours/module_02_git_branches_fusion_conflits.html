Module 02 : Branches, Bascule (git switch) & Résolution de Conflits (git merge)

Formateur : Jean-Marie Renouard (LightPath SARL) • Durée : 2h30 • Niveau Bloom C3

Points Clés sur les Branches & Fusions

  • Pointeurs légers : chaque branche pointe sur un commit SHA, et HEAD indique la branche active.
  • Création et navigation : git switch -c feat/nom isole chaque fonctionnalité sans perturber main.
  • Topologies de fusion : Fast-Forward (historique linéaire) versus 3-way merge (commit de fusion à deux parents).
  • Conflits : suppression des marqueurs <<<<<<<, =======, >>>>>>> puis git add et git commit.

Commandes de Référence

Commande Effet sur le Graphe Contexte Recommandé
git switch -c feat/tva Crée et active la branche Démarrage d'une nouvelle tâche isolée
git merge --no-ff feat/tva Crée un commit de fusion explicite Intégration traçable dans main
git merge --abort Restaure l'état pré-fusion Annulation propre d'une fusion en conflit
git branch -d feat/tva Supprime la branche fusionnée Nettoyage après intégration validée
