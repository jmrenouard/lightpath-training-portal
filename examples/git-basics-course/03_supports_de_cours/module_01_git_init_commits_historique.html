Module 01 : Initialisation d'un Dépôt, Index (Staging) & Premiers Commits

Formateur : Jean-Marie Renouard (LightPath SARL) • Durée : 2h00 • Niveau Bloom C2

Points Clés du Cycle de Vie Local

  • Les trois zones : Working Directory, Staging Area (.git/index) et Dépôt local (.git/objects).
  • Initialisation propre : git init, identité git config et protection .gitignore dès le démarrage.
  • Contrôle avant validation : git status, git diff et git diff --staged.
  • Correction locale : git restore --staged pour désindexer sans perte de travail.

Commandes de Référence

Commande Zone Ciblée Rôle Opérationnel
git init Dépôt .git Crée l'arborescence interne du nouveau dépôt local
git add <fichier> Working Tree → Index Prépare sélectivement les fichiers pour le prochain commit
git commit -m "..." Index → Dépôt Enregistre un instantané atomique dans l'historique
git log --oneline --graph Historique Affiche la chronologie compacte des commits validés
